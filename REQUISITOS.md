# Vecinos de Ferrocarriles Nacionales 830

## Objetivo

Sistema web para la administración de la unidad habitacional.

---

## Roles

### Administrador

- Gestionar residentes
- Gestionar pagos
- Crear avisos
- Ver reportes
- Administrar incidencias

### Residente

- Ver adeudos
- Realizar pagos
- Reportar incidencias
- Consultar avisos
- Descargar comprobantes

---

## Compatibilidad

- Android
- iPhone
- Tablet
- Computadora

---

## Tecnologías

- React
- Firebase
- Bootstrap
- GitHub
- PWA

---

## Funcionalidades futuras
