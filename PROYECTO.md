# Vecinos de Ferrocarriles Nacionales 830

Sistema web para la administración de la unidad habitacional.

## Tecnologías

- React
- Vite
- Bootstrap
- Firebase
- Axios
- React Router
- Git
- GitHub

## Objetivos

- Gestión de pagos.
- Avisos comunitarios.
- Reporte de incidencias.
- Historial de pagos.
- Administración de residentes.

## Requisitos

### REQ-001
Aplicación responsive compatible con Android, iPhone y escritorio.

### REQ-002
Desarrollo Mobile First.

### REQ-003
Implementación futura como Progressive Web App (PWA).

### REQ-004
Roles:
- Administrador
- Residente

### REQ-005
Autenticación mediante Firebase.
